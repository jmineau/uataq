Laboratory.get_site(SID)[source]#

Return site object from config file

Parameters:

SID (str) – The site ID.

Returns:

A site object.

Return type:

Site

Raises:

  • ValueError – If the site ID is not found in the configuration file.

  • ValueError – If no instruments are found for the specified site.
