Functions and modules#

Each class and function has a page of its own. A class page lists its attributes and methods, each with a page of its own, and links to what it inherits from the classes it extends.

Reading data#

What each argument means is written once, on Input Parameters.

read_data

Read data from an instrument at a site.

get_obs

Get observations from a site.

get_recent_obs

Get recent observations from a site.

get_network_obs

Get observations for a network of sites for a single pollutant.

Network

Container for combining and analyzing data across multiple sites for a single pollutant.
